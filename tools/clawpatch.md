# Clawpatch

**Original project:** [openclaw/clawpatch](https://github.com/openclaw/clawpatch)  
**Creator:** Peter Steinberger (steipete) and contributors  
**Type:** Developer tool for automated code review and fixes  
**Verification:** Personally Verified

Clawpatch helps automate code review and work through proposed fixes. It is listed under **tools**, rather than described as a standalone agent skill.

**Get started:** [Official repository and installation documentation](https://github.com/openclaw/clawpatch). Check upstream prerequisites and current supported workflows.

**Example workflow:** Run the tool on a feature branch, inspect findings, verify proposed changes with tests, and submit a pull request for review.

**Why it belongs here:** Useful in a development workflow that combines coding agents with disciplined code review.

**Caution:** Review permissions for repository writes and automated changes; preserve branch protection and human review.
