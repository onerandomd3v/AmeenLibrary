# Contributing

Have a useful skill, tool, MCP server, workflow, or configuration to share? Contributions are welcome!

1. Pick the right section.
2. Explain what it does and why it's useful.
3. Link to the original creator and official setup instructions.
4. Say whether you've used it yourself. Untested discoveries are welcome—just label them **Not Yet Verified**.
5. Open a pull request.

Keep entries short and practical. Use the [resource template](docs/resource-template.md) if helpful.

Please don't include secrets, private information, or third-party content you don't have permission to redistribute.

See our [curation policy](docs/curation-policy.md) for verification labels. Codex and Claude Code are our initial focus, but other agents are welcome.
