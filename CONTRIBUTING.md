# Contributing

Thanks for helping improve AmeenLibrary!

## Before submitting

- Prefer tools and workflows you've used firsthand; describe your experience and limitations.
- Explain what the resource does, when to use it, setup requirements, and a practical example.
- Link the original author or project and state its license when known.
- Do not redistribute third-party code or instructions without permission under their license.
- Remove credentials, tokens, private endpoints, and sensitive information.
- Open a pull request describing your changes and how you verified them.

Suggestions and corrections are welcome through issues.
