# Contributing

Thanks for helping improve AmeenLibrary!

AmeenLibrary started as a personal collection of useful agent skills, developer tools, MCP servers, workflows, and configurations. Contributions from other developers are welcome, including useful discoveries that have **not yet been tested**.

## Before submitting

- Choose the correct category: skill, tool, MCP server, workflow, or configuration.
- Explain what the resource does, why it is useful, and provide a practical example.
- Credit the original author and link the canonical source. State the license when confirmed.
- Link upstream installation documentation by default; avoid copying instructions that may become outdated.
- Disclose whether you have actually used the resource. Do not claim firsthand verification on someone else's behalf.
- Report Codex, Claude Code, and other agent compatibility only when supported by evidence; use Not evaluated when unknown.
- Do not redistribute third-party code or instructions without appropriate licensing or permission.
- Remove credentials, tokens, private endpoints, personal data, and sensitive information.
- Open a pull request explaining the change, verification status, and limitations.

Suggestions and corrections are also welcome through issues.

## Verification and publishing

See the [curation policy](docs/curation-policy.md) for **Personally Verified**, **Community Verified**, and **Not Yet Verified** labels. All three may be included when clearly identified; unverified inclusion is not an endorsement.

Use the [resource entry template](docs/resource-template.md) for catalog entries. Adapt the template for original workflows and configurations. A template or example should not claim end-to-end testing unless it has been performed.

Codex and Claude Code are initial documentation priorities, not exclusive requirements.
