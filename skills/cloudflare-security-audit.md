# Cloudflare Security Audit Skill

**Original project:** [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)  
**Creator:** Cloudflare  
**Type:** Agent skill  
**Verification:** Personally Verified

Guide structured, evidence-based security reviews of software, with attention to real code paths and trust boundaries.

**Get started:** [Official repository and setup instructions](https://github.com/cloudflare/security-audit-skill). Use the upstream skill documentation for installation and supported environments.

**Example prompt:** “Use the security audit skill to inspect our authentication and authorization boundaries. Cite relevant code paths, separate confirmed issues from hypotheses, and suggest scoped fixes.”

**Why it belongs here:** Helps keep agent-assisted security reviews systematic and actionable.

**Caution:** Only audit systems you are authorized to inspect. Skill output is not a substitute for independent security validation.
