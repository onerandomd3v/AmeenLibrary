**Original project:** [tt-a1i/archify](https://github.com/tt-a1i/archify)  
**Creator:** tt-a1i

Create source-grounded, interactive architecture, workflow, sequence, and data-flow diagrams. I have used Archify to document real application subsystems.

**Get started:** [Official setup and installation](https://github.com/tt-a1i/archify#quick-start). Use upstream instructions for current Codex, Claude Code, and other agent support.

**Example prompt:** “Use Archify to inspect the authentication and session flow in this codebase. Build an architecture diagram grounded in source files, and verify the final diagram.”

**Why it belongs here:** Makes architecture discussions and reviews easier to understand while keeping diagrams tied to implementation evidence.

**Caution:** Review diagrams against source code; generated visualizations can omit important details.
