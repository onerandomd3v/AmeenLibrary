# Agent Reach

**Original project:** [Panniantong/agent-reach](https://github.com/Panniantong/agent-reach)  
**Creator:** Panniantong  
**Type:** Agent skill and supporting CLI toolkit  
**Verification:** Personally Verified

Give AI agents access to information from supported external sources and services.

**Get started:** [Official installation guide](https://github.com/Panniantong/agent-reach/blob/main/docs/install.md). The project supports skill-based installation as well as its own CLI; follow upstream requirements for each source.

**Example prompt:** “Use Agent Reach to retrieve public information about this open-source project and summarize its capabilities with source links.”

**Why it belongs here:** Reduces the friction of connecting an agent to research sources during development.

**Caution:** Some integrations need credentials, cookies, network access, or additional dependencies. Review requested permissions and approve system changes deliberately.
