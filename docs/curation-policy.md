# Curation policy

AmeenLibrary is a personal collection of useful developer resources that also welcomes community contributions.

## What belongs here?

- **Skills:** Reusable agent skills.
- **Tools:** Developer utilities.
- **MCP Servers:** Connections between agents and services.
- **Workflows:** Practical development processes.
- **Configurations:** Reusable settings and templates.

## Verification

Every resource should have one clear label:

- **Personally Verified:** I've used it myself.
- **Community Verified:** A contributor has used it and shared their experience.
- **Not Yet Verified:** It looks useful, but hasn't been tested by us yet.

All three can be published. Verification does **not** mean a security audit or a guarantee that the resource works everywhere.

## Simple rules

1. Explain what the resource does and why it's useful.
2. Credit its creator and link the original source.
3. Link to official setup instructions instead of copying long guides.
4. Be clear about what has and hasn't been tested. Don't assume compatibility with Codex, Claude Code, or other agents.
5. Don't publish secrets, private information, or third-party code without appropriate permission.
6. Submit changes through a pull request for review.

See the [resource template](resource-template.md) for a starting point.
