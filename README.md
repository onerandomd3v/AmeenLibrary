# AmeenLibrary

A curated collection of the AI agent skills, plugins, MCP servers, configurations, and workflows I use to build and ship software faster.

This library is built from tools I've actually used. Each entry will explain what it does, why it's useful, and how to get started.

## Sections

- `skills/` — Agent skills
- `plugins/` — Plugins and integrations
- `mcp-servers/` — MCP server references and setup guides
- `workflows/` — Real-world workflows
- `configurations/` — Reusable, sanitized agent configurations

Third-party projects will be credited and linked. No private credentials or project secrets will be published.
