# AmeenLibrary

A curated, open-source collection of agent skills, MCP servers, developer tools, workflows, and configurations that help me build software.

It started as my personal toolkit, but contributions and useful discoveries are welcome. Every resource is labeled **Personally Verified**, **Community Verified**, or **Not Yet Verified**, so you know what's been tested.

## How it works

We keep entries short: what a resource does, why it's useful, and where to find its official documentation. We credit creators and clearly label what has or hasn't been tested.

See the [curation policy](docs/curation-policy.md) for verification labels or [contribute a resource](CONTRIBUTING.md). Codex and Claude Code are initial priorities, but other agents are welcome.
