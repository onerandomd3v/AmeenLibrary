# AmeenLibrary

A curated, open-source library of agent skills, MCP servers, developer tools, configurations, and workflows that help me build and ship software more effectively.

It started as my personal toolkit and is open to community contributions and useful discoveries. Some resources are personally verified, some are verified by contributors, and others are clearly marked as not yet verified.

## Principles

- **Transparent verification:** Distinguish firsthand use, community testing, and resources not yet evaluated.
- **Actionable:** Explain purpose, limitations, and practical usage; link upstream setup instructions rather than duplicating them.
- **Respect creators:** Credit third-party maintainers and link original sources. Redistribute only when licensing allows.
- **Secure by default:** Never publish credentials, secrets, or private project context.

## Curation

AmeenLibrary uses a [hybrid curation and verification policy](docs/curation-policy.md). Use the [resource entry template](docs/resource-template.md) when contributing entries. Codex and Claude Code are initial documentation priorities, but other agents are welcome.
