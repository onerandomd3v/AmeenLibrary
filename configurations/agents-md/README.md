# Reusable AGENTS.md template

Copy [AGENTS.md](AGENTS.md) into the **root of your own repository** and replace every bracketed placeholder. Do **not** copy it into the root of AmeenLibrary unless you intend these instructions to govern AmeenLibrary itself.

The template is deliberately generic. Adapt it to your stack, real test commands, integration branch, and risk controls. Never publish secrets or internal deployment details.

**Compatibility:** Codex documents repository-level `AGENTS.md` discovery and supports more specific nested guidance. Other coding agents may have different instruction-file conventions; confirm support before assuming this file is automatically loaded.

**Validation:** Start a new Codex session in your repository and ask it to summarize the instructions it loaded. Check that the integration branch, commands, and directories are correct.

**Official references:** [Codex AGENTS.md guidance](https://learn.chatgpt.com/docs/agent-configuration/agents-md) · [Codex customization](https://learn.chatgpt.com/docs/customization/overview)

**Status:** Generic template reviewed against official Codex documentation; not a claim of deployment or testing in every environment.
